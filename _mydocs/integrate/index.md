[DaxLib.Client](https://www.nuget.org/packages/DaxLib.Client) is the NuGet package that can be used by external tools to integrate with [DaxLib](https://daxlib.org) directly:
- Create packages
- Download packages

**NOTE**: The client does not add the functions to the semantic model. The external tool (for example, Tabular Editor) adds the functions to the model.
